# The Funniest Office Joke

One line about office life — the whole entry. The program writes the joke
to `/output/entry.txt` for the make.fun bounty "The Funniest Office Joke,
Judged Head to Head".

> I told the printer it was out of toner, so it printed a 40-page error report to prove me wrong.

Run it with Node 22: `node main.ts` (it writes to `$MAKEFUN_OUTPUT_DIR`
when set, otherwise `/output`).
